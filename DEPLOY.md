# Публикация KomekAI

Сайт и API работают в одном Node.js сервисе. Нужен Node.js 22.16 или новее и постоянный диск для SQLite.

## Настройки хостинга

- Команда сборки: `npm ci --include=dev && npm run build`
- Команда запуска: `npm start`
- Проверка здоровья: `/api/status`
- `NODE_ENV=production`
- `HOST=0.0.0.0`
- `PORT` задаётся хостингом.
- `KOMEKAI_DB_PATH` указывает на файл внутри постоянного диска, например `/var/data/komekai.sqlite`.
- `APP_ORIGIN` — публичный HTTPS адрес сайта.
- `GROQ_API_KEY` — секрет в настройках хостинга, если нужен AI.

На Render подключите постоянный диск с путём `/var/data`. Для Docker подключите том к `/app/data`. Запускайте одну копию приложения с этой SQLite базой. Без постоянного диска аккаунты и прогресс могут пропасть при перезапуске или обновлении сервиса.

Если нужен Google-вход, настройте OAuth и задайте `GOOGLE_REDIRECT_URI` как `<публичный HTTPS адрес>/api/auth/google/callback`.

## Проверка перед публикацией

```powershell
npm run build
npm run smoke:production
```

Файл `.env` и локальная база учеников не включаются в Docker образ. Новый хостинг создаёт новую базу. Перенос существующих аккаунтов выполняется отдельно.
