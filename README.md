# KomekAI

Адаптивная учебная платформа на русском и казахском языках. В проекте есть регистрация ученика и родителя, учебный онбординг, диагностика, персональный маршрут, пять предметов, интерактивные задания, XP и серия дней, разбор ошибок, настройки доступности, AI-тьютор, помощник и голосовой разбор с редактируемой расшифровкой.

## Локальный запуск

Нужен Node.js с поддержкой `node:sqlite` (проверено на Node.js 22). Установите зависимости и создайте `.env` по образцу `.env.example`:

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

Откройте `http://127.0.0.1:5173`. Команда `npm run dev` запускает интерфейс и API в одном процессе на одном адресе. Второй сервер на порту 3001 для кабинета больше не нужен. Данные аккаунтов и учебного прогресса хранятся в SQLite в `data/komekai.sqlite`. Каталог уроков находится в `server/content.js`.

## Настройка интеграций

- Добавьте `GROQ_API_KEY` в `.env`. AI-тьютор и помощник используют Groq Chat Completions, голосовые записи — Groq Audio Transcriptions. Модели задаются через `GROQ_MODEL` и `GROQ_TRANSCRIPTION_MODEL`. Ключ хранится на сервере и не включается в клиентскую сборку. OpenAI API-ключ больше не используется.
- Для входа через Google задайте `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI` и `APP_ORIGIN`. Разрешённый redirect URI в Google Cloud должен в точности совпадать с `GOOGLE_REDIRECT_URI`. Пока параметры отсутствуют, интерфейс объясняет, что Google-вход не настроен; вход по email работает.
- Для голосового разбора браузеру нужен доступ к микрофону. После расшифровки ученик может поправить текст перед отправкой тьютору.

## Проверка

```powershell
npm run build
npm run smoke
npm run smoke:web
```

Smoke-проверка запускает отдельный сервер с временной SQLite-базой и проверяет регистрацию, диагностику, задания, XP, серию дней и разделение доступа родителя и ученика.

## Текущие границы

Визуальные уроки — интерактивные анимированные схемы с главами и текстом, а не снятые видеоролики. Учебный профиль служит для выбора подачи материала и не является медицинской диагностикой. Перед публичным запуском для детей потребуются юридическая проверка обработки данных, эксплуатационный мониторинг, резервное копирование и полноценная проверка безопасности.
